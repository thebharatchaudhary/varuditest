# Varudi Enterprise - Official Web Application

> **"Khedut Na Mape, Khedut Mate" | "By the farmer, for the farmers"**

Varudi Enterprise is a premier manufacturer and supplier of agricultural protective covers, premium heavy-duty HDPE tarpaulins, pond liners, vermibeds, azolla beds, and custom vehicle covers.

---

## 🌟 Key Features

- **Multilingual Support**: Real-time seamless switching between **English**, **Gujarati (ગુજરાતી)**, and **Hindi (हिन्दी)**.
- **Comprehensive Product Catalog**:
  - Heavy-Duty HDPE & LDPE Tarpaulins (120 GSM to 450+ GSM)
  - Agricultural Azolla Beds & IS:15907 Vermibeds
  - Bio-floc & Multilayer Pond Liners
  - Biogas Tubes & Silage Covers
  - Custom Tailored Vehicle & Tractor Hood Covers
- **Interactive Inquiries & Quotation**: Integrated quick quote requests with instant WhatsApp and call direct routing.
- **Responsive & Modern UI**: Tailored for both desktop and mobile devices with fast loading times and optimized assets.

## 🚀 Getting Started

### Local Development
You can run this project locally without any complex build steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/thebharatchaudhary/varuditest.git
   cd varuditest
   ```

2. Open `index.html` directly in any modern web browser, or start a local PowerShell server:
   ```powershell
   powershell -ExecutionPolicy Bypass -File server.ps1
   ```
